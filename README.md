# stock_acc — 股票記帳

純前端的股票交易記帳與統計工具，直接用瀏覽器開啟 `index.html` 即可使用，資料存在瀏覽器 localStorage。

## 功能
- **新增交易**：日期、股票代號/名稱、買賣、股數、成交價；手續費（0.1425%，最低 20 元）與賣出交易稅（0.3%）留空時自動計算。
- **股票統計**（依代號彙總，移動平均成本法）：持有股數、平均成本、持有成本、市值、未實現損益、已實現損益、交易次數，以及合計。可在表格中輸入現價計算市值與未實現損益。
- **交易紀錄**：列出所有交易並可刪除。
