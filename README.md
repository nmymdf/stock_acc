# 股票記帳

多人多帳戶的股票交易記帳與統計 App。用 Flutter 寫，同一份程式碼可以編譯成
**Windows 版**和 **Android 版**。資料只存在裝置本機，不會上傳到任何雲端伺服器。

程式碼在 [`app/`](app) 資料夾。

## 功能（第一階段）

- **多人多帳戶**：可以新增多個人，每個人底下可以有多個券商帳戶，各自設定
  手續費折扣。
- **交易紀錄**：新增、修改、刪除買賣交易。手續費（0.1425% × 帳戶折扣，最低
  20 元）和交易稅（賣出 0.3%）會自動算好，也可以手動改成對帳單上的實際金額。
- **統計**：個股 → 個人（可再細分到每個券商帳戶）→ 全部人合計，三層都有
  持股、成本、市值、未實現／已實現損益。
- **即時股價**：按「更新股價」抓證交所的即時報價，可以隨時手動更新。
- **查詢股票**：輸入代號或名稱查詢任何台股，不限自己持有的。
- **資訊 / 新聞**：抓 Google 新聞，列出持有中和關注股票的近期新聞，同一則
  被多家媒體轉載時會合併成一則。可以把還沒買的股票加入「關注清單」。
- **備份**：匯出、匯入 JSON 備份檔，換裝置或重灌時用來還原資料。
- **畫面自動適應**：視窗夠寬（電腦）時左選單／中列表／右明細三欄顯示；
  視窗窄（手機）時换成一般的手機排版，同一份程式碼、同一份邏輯。

## 開發環境

這個開發環境（雲端容器）沒有 Android SDK，也不是 Windows，所以沒辦法在這裡
直接編出 `.apk` 或 `.exe`。改用 **GitHub Actions** 在每次 push 之後，用真正
的 Windows 和 Android 環境編譯：

1. 到 repo 的 **Actions** 分頁，找到「編譯 Windows / Android」這個 workflow
   最新一次執行。
2. 執行完成後，下面的 **Artifacts** 會有 `stock_acc-windows`（解壓縮後執行
   `stock_acc.exe`）和 `stock_acc-android`（`app-release.apk`，直接傳到手機
   安裝，需要先允許「安裝不明來源的 App」）。

本機這裡能做、也已經做過的檢查：
```bash
cd app
flutter analyze   # 靜態檢查，沒有錯誤或警告
flutter test      # 手續費、統計、新聞合併邏輯的單元測試，全數通過
flutter build linux --debug   # 驗證程式碼能真的編譯、啟動，不會一開就當掉
```

## 架構

```
app/lib/
  models/       資料模型（人、帳戶、交易、關注清單）
  logic/        純計算邏輯：手續費／交易稅、移動平均成本法統計（有單元測試）
  data/         本機存檔（JSON 檔）、資料中樞 AppRepository、內建股票代號表
  services/     抓即時股價（證交所）、抓新聞（Google News）
  ui/           畫面：主題、共用元件、導覽殼、各分頁畫面
```

資料存檔是一個 JSON 檔，放在系統的「應用程式資料」資料夾。「匯出備份」就是
把這個 JSON 另存一份，「匯入備份」就是整包讀回來取代——這也是格式已經預留
給第二階段雲端同步的地方：每筆資料都有 `id` 和 `updatedAt`，之後接上雲端時
可以直接拿來判斷哪筆比較新，不用重新設計資料結構。

## 之後的規劃

- **第二階段**：登入 + 雲端同步，手機和電腦資料互通。
- **第三階段**：資訊頁擴充指標圖形、法人買賣、股利等。
- 個股分析（指標、回測、停損停利提醒）規劃成另一個獨立模組，之後另外討論。
